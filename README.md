## 🔭 What I'm working on

### [Argus](https://github.com/MulittleGoji/ArgusAPI)

A REST API written in Python that exposes information about the machine it runs on (CPU, memory, disk, processes, network interfaces) and discovers devices on the local network.

- Automatic network discovery that works on any network without configuration
- Concurrent host scanning with `ThreadPoolExecutor`
- API key authentication through a global FastAPI dependency
- Next steps: metrics history with SQLite, remote access with Tailscale and a dashboard
